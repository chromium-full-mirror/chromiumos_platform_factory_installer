# ChromeOS Factory UFS

Factory UFS is used to do UFS provisioning.

## Build
Factory UFS is built with `factory_ufs`:

```
(inside chroot)
cros-workon --board $BOARD start factory_ufs
emerge-$BOARD factory_ufs
```

then you can find the built binary in `/build/$BOARD/usr/sbin/factory_ufs`.

## Run
Factory UFS provides three functions: clobber, show and provision.

### Clobber
This function first discards the stateful partition by calling `blkdiscard`.
It then enables purge operation and waits until the operation is finished.
```
# Run clobber with default parameters.
> factory_ufs clobber
# Run clobber without purging.
> factory_ufs clobber -p 0
```

### Provision
This function provisions the UFS if the current config on DUT is different from
the config generated by `factory_ufs`. It also rescans the PCI to reload the
config.
```
# Run the provisioning with default parameters.
> factory_ufs provision
# Run the provisioning with 30 seconds PCI rescan timeout.
> factory_ufs provision -p 30
```
