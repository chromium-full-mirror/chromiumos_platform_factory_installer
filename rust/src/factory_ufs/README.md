# ChromeOS Factory UFS

Factory UFS is a tool which supports:

- provisioning the UFS (provision)
- showing the content of a UFS config (show)
- cleaning up the stateful partition of a UFS storage (clobber)


## Build
Factory UFS is built with `factory_ufs`:

```
(inside chroot)
cros-workon --board $BOARD start factory_ufs
emerge-$BOARD factory_ufs
```

then you can find the built binary in `/build/$BOARD/usr/sbin/factory_ufs`.

## Run
Factory UFS provides three functions: clobber, show and provision.

### Clobber
This function first discards the block device by calling `BLKDISCARD` ioctl.
If purge operation is enabled, factory_ufs waits until the operation is finished.
```
# Run clobber on /dev/sda1 without purging.
> factory_ufs clobber /dev/sda1
# Run clobber with purging timeout set to 300 seconds.
> factory_ufs clobber /dev/sda1 -p 300
```

### Provision
This function provisions the UFS if the current config on DUT is different from
the config generated by `factory_ufs`. It also rescans the PCI to reload the
config.
```
# Run the provisioning with default parameters.
> factory_ufs provision
# Run the provisioning with 30 seconds PCI rescan timeout.
> factory_ufs provision -p 30
```

## File Hierarchy
```
factory_ufs
|-- action
|-- ufs
|   |-- descriptor
|   `-- spec
`-- utils
```

- action
  - Implements the clobber, provision and show subcommands.
- ufs
  - descriptor
    - Contains four kinds of descriptors: common, config, device and unit.
      - Common descriptor defines the common trait that every descriptor needs
        to implement.
      - Config descriptor consists of 1 device descriptor and 8 unit
        descriptors.
    - Defines the trait that each spec needs to implement.
  - spec
    - Defines the fields in device and unit descriptors.
    - Implements the trait defined in `descriptor`.
- utils
  - Contains path searching and file reading functions specifically for
    factory_ufs.
